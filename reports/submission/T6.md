- Multi-field focus with optional frequency/service, focused structured products and persisted follow-up focus. Legacy scalar focus and numeric filters remain readable/accepted.
- Typed numeric bounds value/op (gt/gte/lt/lte), fixed SQL operator allowlist and direct published units. Strict/inclusive boundary tests include equality at a published torque/power value. User magnitudes are grounded; semantic field/operator interpretation still needs real-model v5 acceptance.
- Ordered SQL preference ranking, stable code tie-breaks, NULLS LAST and top three. Without a requested frequency ranking uses the minimum published frequency-specific value and says so. Motor power is explicitly not total consumption.
- Unsorted result sets above four show count + one entropy-selected SQL facet question without products. Two to four show brief focused values and comparison options; one shows focused data. Empty sets bypass ambiguity and compute SQL extrema under remaining constraints, preserving service/frequency row scope and tied model names. Unknown remaining combinations are stated explicitly.
- Cancel/decline clear pending state appropriately; cancellation clears filters/focus, confirms and reminds scope. Bare cancel/no also override stale inappropriate model tool decisions after the single scripted decision. Cancel executes no catalogue lookup/search. Mixed cancel+new intent confirms cancellation before the new result.
- Difference-only comparison of at most two SQL-verified codes, directional better only for torque/time/current/motor power, identical-field count and SQL-verified pair suggestions for three/four candidates. Answers contain no Markdown tables.
- Exactly three distinct English suggestions per new successful turn. New additive migration 004 persists suggestions/comparison; prior messages read with []/null. Existing migrations, OCR outputs and catalogue data were not edited.
- Android DTOs, ViewModel state, disabled-while-busy tappable chips under the latest assistant turn, and a wrapping three-column comparison card with better value bold and no horizontal scroll. Existing loading/errors/auth/debug/product presentation is retained. Four new JVM contract/model tests cover decoding, old history defaults, reply text and two-model limits.
