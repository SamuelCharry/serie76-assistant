# Project AI tooling

Claude Code coordinates development and review with the `agent-skills` and
`data-analytics-skills` collections. Codex implements changes orchestrated through
Orca. LangSmith provides opt-in runtime traces (disabled by default).

This directory contains project permissions and instructions only. Credentials,
personal memory and global configuration are not included. Public test-only demo
credentials are documented in the root README; they are not production accounts.
